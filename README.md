# Portfolio Chat App

The Portfolio Chat App is an interactive AI-powered portfolio experience designed to help visitors, particularly recruiters and potential employers, learn about the applicant through natural-language conversation.

# Documentation

The project documentation follows the major phases of the Software Development Life Cycle (SDLC). Each document serves a specific purpose and provides traceability from requirements through deployment and maintenance.

| Software Development Phase | Documents | Purpose | Location |
|---|---|---| --- |
| Requirements | Requirements Document | Define what the system must accomplish | /docs/01-requirements/ |
| Planning | Project Plan | Define schedule, resources, costs, scope, and risks | /docs/02-planning/ |
| Design | Architecture Document, API Specifications | Explain how the system will be built | /docs/03-design/ |
| Development | Coding Standards, Technical Specifications, Configuration/Environment Documentation | Keep implementation consistent and maintainable | /docs/04-development/ |
| Testing | Test Cases/Scenarios, Test Data, Defect/Bug Reports | Demonstrate that the software works as expected | /docs/05-testing/ |
| Deployment | Deployment Plan, Release Notes | Define how the software gets into production safely | /docs/06-deployment/ |
| Maintenance | User Manual | Support and maintain the system after release | /docs/07-maintenance/ |
